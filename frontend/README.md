# Crowd Pilot AI — Frontend

The user interface for Crowd Pilot AI. Built with React 19, TypeScript, and Tailwind CSS v4 using Vite.

Provides two main views:
- **Authority Dashboard (`/`)**: Real-time 3×4 zone density grid, live alert feed with recommended actions, people count inside/outside floor outline, occupancy line chart, and pandal capacity controls (Close / Reopen).
- **Public Guide (`/public`)**: Mobile-first visitor routing and pandal status guide (calm tone, word-only statuses, never raw crowd counts).

For system architecture, development instructions, and full setup guides, refer to the root [README.md](../README.md).
